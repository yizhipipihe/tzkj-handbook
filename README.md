## 这个仓库解决什么问题

学校的学生手册动辄上百页，配套题库又是填空、判断、单选、多选混在一起的一坨纯文本。人和 AI 想查"旷课 55 课时到底会怎样"，通常有三种结果：翻半天翻不到、翻到了但对不上条款、AI 直接编一个看起来很像的答案。

这个仓库把题库拆成结构化数据，并额外做了三件事：

1. **每题都有稳定题号**（`TF-001`、`PD-051`、`SC-076`、`MC-120`）。AI 回答时能标注依据，你也能一键回查原题。
2. **人工整理的速查表**。`references/key-facts.md` 按 11 个主题列出数字、比例、期限、流程，260 个题号全部经过存在性校验，多数问题看这一份就够。
3. **矛盾清单**。原始题库本身有答案键错误和互相打架的地方，`references/conflicts.md` 逐条列出并给出倾向，避免 AI 学错。

同时它本身符合 [Agent Skills](https://docs.claude.com/en/docs/claude-code/skills) 规范：放进技能目录就能被 Claude Code 一类工具自动发现；不支持该规范的模型，直接喂 `key-facts.md` 也能用。

## 目录结构

```
tzkj-student-handbook/
├── SKILL.md                    AI 入口：触发条件、使用流程、回答规范
├── README.md                   本文件
├── references/
│   ├── key-facts.md            核心数字与规则速查，逐条标注题号
│   ├── conflicts.md            题库内部矛盾清单与处理建议
│   └── by-topic/               12 份主题题库（原文照录，含目录表与答案）
├── data/
│   ├── questions.jsonl         521 题结构化数据（唯一权威副本）
│   └── questions.csv           同一份数据，便于 Excel / 表格工具查看
└── scripts/
    ├── search.py               题库检索：关键词 / 题号 / 主题 / 题型
    └── build_bank.py           从原始 TXT 重新生成 data 与 by-topic
```

## 快速开始

### 方式一：装成 Agent Skill

```bash
# macOS / Linux
git clone <本仓库地址> ~/.claude/skills/tzkj-student-handbook

# Windows (PowerShell)
git clone <本仓库地址> "$env:USERPROFILE\.claude\skills\tzkj-student-handbook"
```

装好后，AI 遇到"台科院学生手册怎么规定"这类问题会自动加载 `SKILL.md`，再按需读速查表或主题题库。

网页端（支持上传技能的客户端）：把整个目录压缩成 zip 上传即可。

### 方式二：给任意模型当知识文件

- 必带：`SKILL.md` + `references/key-facts.md`（这两份覆盖 80% 以上常见问题）。
- 追问细节时，再按主题补 `references/by-topic/0X-*.md`。
- 长文本模型可以直接把 `data/questions.jsonl` 一起喂进去。

### 方式三：命令行检索

```bash
python scripts/search.py 转专业
python scripts/search.py 旷课 处分 -n 6
python scripts/search.py 请假 --topic 07
python scripts/search.py 比例 --type 单选题
python scripts/search.py --id TF-022
python scripts/search.py --list-topics
python scripts/search.py 奖学金 --json
```

零依赖，只用 Python 3 标准库。`--list-topics` 可以快速确认数据完好：

```
01-学籍与注册: 34 题
...
合计: 521 题
```

## 回答效果示例

**问**：一学期旷课 55 课时会怎样？

> 一学期累计旷课 45–60 课时，给予**留校察看**；连续旷课两周或累计满 60 课时，按**放弃学籍或自动退学**处理（TF-022、TF-086）。55 课时落在留校察看区间，但离 60 课时只差 5 节，而迟到、早退三次按一节旷课计（PD-057），实际很容易越过临界。

**问**：什么时候可以申请转专业？

> 一年级第一学期 **12 月 1 日–10 日**、第二学期 **6 月 1 日–10 日**，其它时间无特殊情况不予受理；在校期间只能转一次（TF-033、MC-005）。

**问**：能借几本书、借多久？

> 一次可借 **10 本**，借期 **3 个月**（专业图书）；假期或实习期间到期的书，返校后第一周内归还不算超期（TF-024、SC-040、TF-013）。

每个结论都带题号，可以立刻回 `data/questions.jsonl` 或对应主题文件核对原文。

## 数据质量与局限

这部分请你务必看，也是本仓库和"随便爬一份题库"的区别所在。

1. **不是官方文件**。内容来自使用者提供的题库 TXT，不是学校发布的《学生手册》原文，可能不含最新修订。
2. **原文档有格式噪声**。来自 OCR/文本转换：选项字母直接紧贴文字（`A4周B1周`）、答案另起一行且偶尔黏在最后一项末尾、正文中夹着 `P147` 之类的页码。`build_bank.py` 已针对这些做了容错，521 题全部解析出答案，无空答案、无重复题号。
3. **答案键有错**。已发现并记录 5 处矛盾，例如：
   - 月文明寝室加分：TF-012 / SC-067 写 2 分，PD-037 写 1 分且判"对"；
   - 私自换寝：TF-017 明确"不得擅自更换"，PD-031 却把"可根据心情私自更换"判"对"。

   处理建议都在 `references/conflicts.md`，遇到时 AI 会说明两种说法而不是硬选一个。
4. **涉及权益请以正式文件为准**。处分、退学、金额、申报截止时间等，题库只能作为复习和检索参考。

## 更新题库

拿到新版原始 TXT 后：

```bash
python scripts/build_bank.py <新题库.txt>
```

脚本会重建 `data/questions.jsonl`、`data/questions.csv` 和 `references/by-topic/*.md`（生成前会清空旧主题文件，避免残留）。若新版题型标记或主题划分变了，改 `scripts/build_bank.py` 顶部的 `TYPE_CODE` 与 `TOPICS` 即可。

`key-facts.md` 与 `conflicts.md` 是人工整理产物，脚本不覆盖，需要按变化手动更新。

## 适合谁用

- **学生**：查规定、核对复习题、考前快速过一遍数字和比例。
- **班干部 / 辅导员助理**：回答同学"这个会不会被处分""奖学金要什么条件"。
- **AI 助手 / 二次开发**：作为一个可加载的校规知识包，或者拿 `questions.jsonl` 做题库应用、自动判卷、问答机器人。

## 贡献

- 发现某题答案有问题：提 Issue，写清**题号 + 依据**（手册页码或官方条款）。
- 修正数据：直接 PR 改 `data/questions.jsonl` 与对应 `references` 文件，**保留原题号**，方便追溯。
- 新增主题或补充题目：同时更新 `scripts/build_bank.py` 的 `TOPICS`，再重跑构建，避免手写文件被下次生成覆盖。
